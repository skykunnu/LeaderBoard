# Dynamic Leaderboard Application

# Overview
The Dynamic Leaderboard Application is an interactive and user-friendly platform for managing a leaderboard in real-time. Users can add, update, and delete player details and adjust scores dynamically. The application automatically sorts players based on their scores, providing a seamless experience for ranking management.

# Features

Add Players: Users can input player details (First Name, Last Name, Country, and Score).
Delete Players: Players can be removed from the leaderboard with a single click.
Update Scores: Users can increment or decrement scores dynamically with "+5" and "-5" buttons.
Real-Time Sorting: The leaderboard automatically updates and sorts players based on their scores in descending order.
Input Validation: Ensures all required fields are filled before adding a player.
Responsive UI: Clean and interactive user interface built for an engaging experience.
